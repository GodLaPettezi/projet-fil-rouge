# Portfolio photographique — Solène Avril

Présentation d'un site web consacré à l'univers artistique d'une photographe. Ce projet met en avant ses différentes réalisations à travers une interface moderne, minimaliste et adaptée à tous les écrans.

🔗 **Démo en ligne :** [Découvrir le portfolio](https://ismailoumghar3110-bot.github.io/Projet-fil-rouge/)

## Technologies utilisées

- HTML5 (structure des pages)
- CSS3 (design et mise en forme)
- Flexbox et CSS Grid (organisation des éléments)
- Media Queries (adaptation aux différents écrans)

## Fonctionnalités

- Navigation entre plusieurs catégories de photographies.
- Galerie d'images organisée avec CSS Grid.
- Affichage responsive sur ordinateur, tablette et mobile.
- Mise en valeur des photographies grâce à un design épuré.
- Intégration d'icônes pour améliorer la navigation.
- Utilisation de Google Fonts pour personnaliser la typographie.
- Présentation visuelle pensée pour faciliter la découverte des œuvres.
