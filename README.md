# Portfolio — Solène Avril

Présentation d'un site web consacré à une photographe. Ce projet met en avant ses différentes photos avec une interface moderne et adaptée à tous les écrans.

 **Page Web :** [Découvrir le portfolio](https://ismailoumghar3110-bot.github.io/Projet-fil-rouge/)

## Technologies utilisées

- HTML5 (structure des pages)
- CSS3 (design et mise en forme)
- Flexbox et CSS Grid (organisation des éléments)
- Media Queries (adaptation aux différents écrans)

## Fonctionnalités

- Galerie d'images organisée avec CSS Grid.
- Affichage responsive sur différent appareils avec media queries
- Utilisation de Google Fonts pour personnaliser les polices.
- Utilisation de Font Awesome pour les photos
