Portfolio photographique — Solène Avril

Création d'un site web vitrine pour mettre en valeur le travail artistique d'une photographe. Le projet propose une interface élégante et épurée permettant de découvrir différentes séries de photographies à travers une galerie organisée par thèmes.

🔗 Accéder au projet : Voir le portfolio en ligne

Technologies utilisées
HTML5 : organisation et structuration des différentes sections du site.
CSS3 : mise en forme, animations et personnalisation graphique.
CSS Grid & Flexbox : création d'une galerie et gestion des éléments.
Media Queries : adaptation de l'affichage aux différentes tailles d'écran.
Points forts du projet
Interface sobre mettant l'accent sur les photographies.
Navigation intuitive grâce à un menu de catégories.
Présentation des images sous forme de galerie dynamique.
Affichage adapté aux ordinateurs, tablettes et smartphones.
Intégration d'icônes pour enrichir l'expérience visuelle.
Utilisation de polices personnalisées pour renforcer l'identité du site.
Mise en page pensée pour offrir une expérience de consultation agréable.

Objectif du projet

Ce travail avait pour but de développer un site esthétique et responsive, tout en mettant en pratique les bases de l'intégration web. Il permet également d'explorer différentes techniques CSS pour créer une galerie photographique harmonieuse et agréable à parcourir.
